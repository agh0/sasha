# Svoislova — замена иностранных слов

## Что использовать

Все запросы к API делай через bundled script:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/svoislova/scripts/analyze.py" --text 'Ваш текст'
```

Допустим и ввод через stdin:

```bash
printf '%s' 'Ваш текст' | python3 "${CLAUDE_PLUGIN_ROOT}/skills/svoislova/scripts/analyze.py"
```

Скрипт делает `POST https://svoislova.ru/analyze` и печатает только JSON-ответ в stdout. Ошибки пишет в stderr и завершает с ненулевым кодом.

## Алгоритм

1. Запусти скрипт на всём тексте пользователя.
2. Из ответа возьми токены с `risk = "high"` и токены с `risk = "medium"`, которые остаются проблемными после проверки лемм и контекста.
3. Для каждого проблемного слова придумай до 5 валидных русских замен.
4. Каждую замену проверяй тем же скриптом, передавая только саму замену.
5. Собери итог: таблица замен и переписанный текст.

## Правило для `medium`

Если у токена есть русская лемма, которая подходит по контексту, понизь риск до `low` и не включай слово в замену.

Примеры:
- `матч` + `["match", "матч"]` -> пропустить
- `план` + `["plan", "план"]` -> пропустить
- `трафик` + `["traffic"]` -> считать проблемным

## Генерация и проверка замен

- На одно слово трать не более 10 проверок.
- Остановись раньше, если уже нашлось 5 валидных замен.
- Учитывай контекст, грамматическую форму, стиль и смысл.
- Отбрасывай кандидатов, у которых после проверки есть `risk = "medium"` или `risk = "high"`.
- Если ни одна замена не прошла проверку, помечай слово как `замена не найдена`.

Примеры:
- `дедлайн` -> `срок`, `крайний срок`, `контрольная дата`
- `митинг` -> `совещание`, `собрание`, `встреча`
- `трекер` -> `планировщик`, `система учёта`, `журнал задач`

## Вывод

Не показывай пользователю:
- команды;
- сырой JSON;
- промежуточные шаги;
- объяснение процесса;
- служебные комментарии вроде `проверил`, `нашёл`, `сделал запрос`.

Показывай только итоговый результат.

Если проблемных слов нет, ответ должен быть одной строкой:

```text
Проблемных заимствований не найдено.
```

Если проблемные слова есть, выведи только:

```markdown
| Слово в тексте | Риск | Рекомендуемые замены |
|---|---|---|
| дедлайн | 🔴 high | срок, крайний срок, контрольная дата |
| митинг | 🟡 medium | совещание, собрание |
| трекер | 🔴 high | *(замена не найдена)* |

Переписанный текст:
...
```

## Важные детали

- Подгоняй форму слова под контекст: `на митинге` -> `на совещании`.
- Не меняй слова с `risk = "low"`.
- Сохраняй порядок появления слов в таблице.
- Повторяющиеся слова показывай в таблице один раз, но заменяй во всём тексте.
- Сохраняй форматирование, пунктуацию и структуру исходного текста.
